# 📊 Customer Churn Prediction using Machine Learning

Customer churn has a direct impact on a company’s revenue and long-term growth. In this project, we build an end-to-end Machine Learning model to identify customers who are most likely to churn and help businesses take proactive action to retain them.

---

## 🚀 Project Overview

This project focuses on building a predictive model that uses customer behavior and service usage attributes to determine whether they are likely to discontinue service (**churn**).

The goal is to support subscription-based companies in:
- Increasing **customer retention**
- Improving **Customer Lifetime Value (CLTV)**
- Identifying **at-risk users** to target with retention strategies

---

## 📈 Results & Insights

✨ Random Forest & XGBoost delivered best performance  
✨ Key drivers of churn:
- Short service tenure
- Lack of tech support
- Higher monthly charges
- Frequent customer support calls

📌 These insights enable companies to **reduce churn** using:
- Loyalty rewards  
- Better support experience  
- Targeted discount campaigns
